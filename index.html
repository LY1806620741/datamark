使用说明

纯前端单文件工具：无后端、无上传，所有标注与媒体解析都在这台机器的浏览器里完成。首次访问会自动走一遍三步引导，随时可点右上「引导」重看。

零、30 秒上手

① 点「导入媒体」选音频/视频，或点「连接目录」一次读入整个目录；② 左边选中一项，音频改文稿、视频拖框标注；③ 点「导出标注」，拿单一数据文件或只读预览 HTML。数据默认存在本机浏览器，连上目录后每次修改会即时写入该目录。

一、录音 / 音频：文稿校对与文字标注

导入音频后，同一目录下的同名 .txt 会自动解析成文稿（格式 【说话人】mm:ss）。逐段校对时可以改说话人、改时间码、改原文，点时间码直接跳转复听；每段可打 ★ 标记为重点，也可在右侧写人工译文（开启「双语对照」后逐段并排显示）。

只有现成的 txt 文稿（格式 【说话人】mm:ss）时，用右上「导入标注」直接选 .txt 就能导入；有音频没文稿时，用工具栏「载入 / 更换音频」把音频挂到当前文稿项上，边播边录段落。

「连接目录」会把目录里的媒体逐步建成条目，并读入同目录的 annotations.json（有的话）；同名 .txt / .json 旧格式也能自动匹配。连上目录后，任何修改都会即时覆盖写入 annotations.json 这一个文件，不会摊出一堆碎片；目录里首次还会生成一份 README.md 说明数据格式。

二、视频：划重点与打码

选中「划重点」或「打码」后用鼠标在画面上拖出一个框，即生成一条带时间范围的标注：框会从当前播放位置开始持续一段时常（默认 3 秒，可在右侧面板改写起止时间）。打码是真实马赛克像素化，不是半透明色块；画框项还没挂素材时，舞台里可以「载入本地视频到本项」，把文件挂到已有标注上（同尺寸素材坐标自动对齐）；也可以一键生成 8 秒演示片段先练手法。

三、接自己的模型（可选）

右上「模型」可以连本机或局域网的 OpenAI 兼容服务（llama.cpp 的 llama-server、Ollama、LM Studio、vLLM 都算）：填地址（如 http://127.0.0.1:8080/v1 或 http://192.168.1.20:8080/v1），点「测试连接」，保存即可。之后音频页的「AI 翻译 ▾」把原文翻成译文并回填译文栏，「转写 ▾」把音频转成文稿段落（有 whisper 服务时按时间码分段）。模型跑在你自己机器上，文字不出内网；没连模型时工具照旧完全可用。

四、导出

「导出标注」里推荐用单一数据文件：连了目录就直接写进 annotations.json，没连目录就下载一份 JSON（含全部文稿、标记、区域坐标，不含媒体本体）。另有只读预览 HTML：把数据（可选内嵌媒体）打包成一个独立文件，别人双击就能看、能播，但改不了，适合发给同事复核。

文稿页还可以单独导出 TXT / SRT（原文或双语）/ Markdown，视频页可导出当前帧截图和打码视频。

「导出打码视频」是按 30fps 逐帧重绘并实时录制成新文件，优先写 MP4（时长与索引完整），浏览器不支持时退到 WebM 并自动补写时长信息。录制耗时约等于片长，期间不要切走标签页；导出的是 VP9/Opus 编码，现代播放器可播，需要 H.264 时用本地转码工具再过一遍。

四、界面语言

右上角语言按钮可切中文 / English / 日本語 / 한국어。英文与常用中文词条是内置的，不连模型也能用；其他语言（以及界面上没覆盖的长文案）会交给「模型」里配置的那个服务翻译，结果缓存在本机，下次打开直接生效。只翻界面文案，你的文稿、文件名、标注说明不会被翻译。

边界说明

打码是马赛克加柔化，强度随区域大小自适应，遮住小字比单纯画半透明色块可靠。区域是静态矩形，只在起止时间内生效；画面里会移动的敏感信息（滚动列表、运动中的人脸）需要沿时间轴多打几段框，本工具不做逐帧跟踪。

音视频能否播放取决于浏览器对该编码的支持（建议 MP4/H.264、MP3、WAV）；画布录制导出是 Chrome / Edge 的能力。所有标注保存在本机浏览器，刷新或重开都还在，换机器请用 JSON 导出迁移。

本机 / 局域网模型

只要是 OpenAI 兼容服务就能接：llama.cpp（llama-server）、Ollama、LM Studio、vLLM 等。地址可填本机 http://127.0.0.1:8080/v1，也可填局域网 http://192.168.1.20:8080/v1。工具本身仍然零依赖、无后端。
被浏览器拦了：页面是 HTTPS，模型是 HTTP（混合内容）
Chrome 直接拒掉 https://… 页面向 http://内网IP 的请求，报 Mixed Content。下面任选一条：
  1. Caddy 一行转发成 HTTPS（推荐，两种系统都有包）
    安装（选你系统的）
    macOSbrew install caddy
    Windowschoco install caddy
    Linuxcurl -sS https://webi.sh/caddy | sh
    运行（把内网模型转成 https://localhost，并补上 CORS 响应头）
    首次跑完执行一次 caddy trust（自签根证书进系统库，不装浏览器会报证书错误）。然后点 ，再点「测试连接」。
    Caddy 和模型跑在同一台机器时端口会撞，把下面命令里的 -from 端口改成 9443 再用。
  2. SSH 转发（不用装东西，但要能 ssh 到那台机器）
    转发后点 ，再「测试连接」。
  3. 给模型自己上 HTTPS：mkcert 签证书 + 客户端装根证书，llama-server --ssl-cert-file cert.pem --ssl-key-file key.pem，地址填 https://192.168.2.78:9931/v1（自签不装根证书，fetch 不认）。
  4. 把页面也变成 HTTP：下载本文件，同目录跑 python3 -m http.server 8000（Windows py -m http.server 8000），开 http://127.0.0.1:8000/index.html。
  5. 外层套 HTTPS 隧道：Cloudflare Tunnel、ngrok http 9931、tailscale serve，地址换成隧道给的那个 https://。
别用 file:// 双击打开：不是可信上下文，「选目录」那套会失效。

连不上时依次查三件事：① 服务是否在跑、端口对不对（llama-server 默认 8080，Ollama 是 11434）；② CORS 是否放行本站来源（llama-server 默认 --cors-origins *，Ollama 需设 OLLAMA_ORIGINS 后重启）；③ 首次调用时浏览器会弹「允许访问本地网络」，点允许。用 file:// 双击打开时多数浏览器禁止连本机服务，请用 https 或 http://localhost 打开本工具。
